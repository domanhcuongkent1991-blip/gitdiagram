# Song ngữ VN/EN cho lớp UI GitDiagram — Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Giao diện GitDiagram hiển thị tiếng Việt hoặc tiếng Anh theo cookie `NEXT_LOCALE` (mặc định `vi`), chuyển bằng nút ở header, URL không đổi.

**Architecture:** next-intl ở chế độ "without i18n routing": `src/i18n/request.ts` đọc cookie qua `getRequestConfig`, merge bản dịch với EN làm fallback; layout (async) nạp `<html lang>` + `NextIntlClientProvider` truyền props xuống; `LocaleSwitcher` set cookie + `router.refresh()`. ISR bị bỏ theo thiết kế (dynamic rendering toàn app).

**Tech Stack:** next-intl (phiên bản mới nhất tương thích Next 16), Next.js 16 App Router, React 19, TypeScript, Tailwind 4, Bun, Turbopack, vitest + testing-library.

**Spec:** `docs/superpowers/specs/2026-10-28-vi-en-ui-i18n-design.md` (chủ nhân đã duyệt 2026-10-28)

## Global Constraints

- KHÔNG sửa bất kỳ dòng nào trong `src/server/generate/prompts.ts` (anti-goal của spec).
- KHÔNG thêm middleware, KHÔNG tạo `[locale]` segment, KHÔNG đổi cấu trúc URL/route.
- `messages/en.json` giữ **nguyên văn** chuỗi gốc hiện có — các test assert text EN phải pass không sửa assert.
- Metadata SEO, sitemap, robots, JSON-LD, OpenGraph và toàn bộ `src/mcp-app/` giữ tiếng Anh (non-goal).
- Trang văn bản dài giữ EN: `/visualize-codebase`, `/privacy`, `/terms`, `/support`.
- Thuật ngữ giữ Anh trong bản dịch VN: commit, branch, pull request, repo, API key, streaming; "diagram" → "sơ đồ"; logo "GitDiagram" giữ nguyên.
- Bản dịch VN phải ngắn gọn; key nào làm vỡ layout thì rút nghĩa, không phóng to khung.
- Không đổi công cụ dev: giữ Turbopack + Bun; nếu plugin next-intl vướng Turbopack thì dùng cấu hình thủ công theo docs next-intl.
- Mỗi task kết thúc: `bun run test` pass và `bun run lint` không lỗi mới commit.
- Commit do phiên thực thi thực hiện theo từng task (chủ nhân duyệt plan = duyệt flow commit; KHÔNG push).

## Review Focus

1. Cookie có giá trị lạ (`fr`, chuỗi rỗng, khoảng trắng) → app phải chạy với locale `vi`, không crash, không render rỗng. Test: Task 1 (bước 1–3).
2. Không có cookie (lần đầu vào) → locale `vi`. Test: Task 1.
3. Key có trong `en.json` nhưng thiếu trong `vi.json` (bỏ sót khi dịch) → hiển thị chữ EN thay vì in nguyên chuỗi key hoặc lỗi. Test: Task 1 (deepMergeMessages).
4. Đổi locale không được gây hydration mismatch: `lang` và messages phải đến từ cùng một nguồn là layout server. Kiểm: Task 4 (bước dev thủ công) + test LocaleSwitcher đọc locale từ provider, không đọc `document.cookie` lúc render.
5. Chữ VN dài hơn EN làm vỡ layout (hero, chip example repos, nút header) → UI check tay cả 2 locale. Kiểm: Task 10 (checklist thủ công).

`request.ts`:

```ts
import { getRequestConfig } from "next-intl/server";
import { cookies } from "next/headers";
import { deepMergeMessages, LOCALE_COOKIE, normalizeLocale } from "~/lib/locale";

import enMessages from "../../messages/en.json";
import viMessages from "../../messages/vi.json";

const MESSAGES: Record<string, unknown> = { en: enMessages, vi: viMessages };

export default getRequestConfig(async () => {
  const store = await cookies();
  const locale = normalizeLocale(store.get(LOCALE_COOKIE)?.value);
  return {
    locale,
    messages: deepMergeMessages(enMessages, MESSAGES[locale]),
  };
});
```
